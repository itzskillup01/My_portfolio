# Ragi's Little Corner ✿

A handmade, scrapbook-inspired personal website for Ragi, a Class 10 student who loves drawing, sketching, painting, cricket, and chess.

## What's inside
- About Ragi and her hobbies
- Achievements: first prize in chess, third prize in cricket
- An art gallery with placeholders ready for real artwork
- A /now-inspired section and a hidden star Easter egg
- Responsive HTML/CSS/JavaScript, with no site builder or template

## Run locally
Open `index.html` in a browser. Internet is only needed for the optional Google Fonts.
Open code in a ide open terminal write start index.html and enter, it will open the project on the browser

## Privacy
I Avoid publishing school name, contact information, exact location, or schedule.
